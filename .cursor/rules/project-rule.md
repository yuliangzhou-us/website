\# Project Rule



\## Stack

\- Use Next.js

\- Use TypeScript

\- Use Tailwind CSS

\- Use App Router



\## Design goals

\- Build an academic personal website

\- Keep the structure professional and research-oriented

\- Homepage should feel like a research showcase

\- Use card-based sections for projects and highlights

\- Keep the site visually stronger than a plain faculty template

\- Do not make it look like a startup landing page



\## Content rules

\- Do not invent detailed real-world achievements

\- Use placeholders where content is not provided

\- Build the structure first, content later



\## Code rules

\- Use reusable components

\- Keep files organized

\- Separate content data from page layout where possible

\- Keep components readable and modular

\- Make all pages responsive
