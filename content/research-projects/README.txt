Research projects use NUMBERED folders only (01, 02, 03, ...). Do not rename folders to project titles.

_order.txt lists those folder names from top to bottom (display order on the site).

Inside each numbered folder:

  slug.txt            One line: URL slug for /projects/<slug> (lowercase, hyphens; stable links if you change title text)
  title.txt           Project title (single line or multiple lines merged into one space)
  sponsor.txt         Sponsor line (single line)
  abstract.txt        Full abstract (saved as one paragraph on the site)
  collaborators.txt   One collaborator per line (shown as a bullet list)

  cover-image.txt     One line: path under public, e.g. /images/research/tamping.png
  video-embed.txt     One line: full YouTube embed URL, or leave empty for no video
  gallery-images.txt  Optional. One image path per line (figures below the video). Leave empty if none.

New project: create the next number folder (e.g. 07), add all files including slug.txt, and add that folder name as a new line in _order.txt.
